UPLOAD TO GITHUB PAGES

1. Upload index.html and style.css to the root of your GitHub repository.
2. Upload the complete assets folder without changing its name or structure. This folder now includes five research images, two MP4 demonstrations, two video poster images, and one laboratory photo.
3. Upload your resume to the repository root and name it AI&Manu.pdf.
4. In GitHub, open Settings > Pages, choose Deploy from a branch, select the main branch and /(root), then save.

If your resume has a different filename, update both AI&amp;Manu.pdf links in index.html.

Publication note: The manuscript is described as submitted to Advanced Materials. Obtain permission from the corresponding author or PI before publicly posting unpublished manuscript figures or results.
